# Automatic Essay Scoring — Small NLP Mini Project

A clean, beginner-friendly implementation of **Automatic Essay Scoring (AES)** using the original ASAP essay-scoring dataset.

## What it does

```text
student essay
    ↓
TF-IDF features + simple essay statistics
    ↓
Ridge regression
    ↓
predicted human-style score
```

The project trains **one model per essay prompt (`essay_set`)** because the original ASAP prompts have different score ranges and scoring contexts.

## 1. Create the environment

### Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks activation, you can run the environment's Python directly instead:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### macOS/Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 2. Get the ASAP dataset

Use the Kaggle competition data page:

https://www.kaggle.com/c/asap-aes/data

Download **`training_set_rel3.xlsx`** and put it here:

```text
data/raw/training_set_rel3.xlsx
```

The dataset is governed by the competition's rules. This project does not redistribute the dataset file.

## 3. Prepare the dataset

```bash
python src/prepare_dataset.py --input data/raw/training_set_rel3.xlsx --output data/processed/asap.csv
```

The prepared CSV keeps the essential columns:

- `essay_id`
- `essay_set`
- `essay`
- `domain1_score`

## 4. Train the models

Start with one prompt first:

```bash
python src/train.py --data data/processed/asap.csv --essay-set 1
```

Or train all prompts:

```bash
python src/train.py --data data/processed/asap.csv --all-sets
```

Each trained model is saved in `models/`.

## 5. Evaluate

```bash
python src/evaluate.py --data data/processed/asap.csv --all-sets
```

You will see:

- RMSE
- MAE
- Quadratic Weighted Kappa (QWK)
- number of test essays

QWK is particularly relevant to the original ASAP task because it measures agreement between the predicted and human-assigned ordinal scores.

## 6. Score a new essay

After training prompt 1:

```bash
python src/predict.py --essay-set 1 --essay "Your essay goes here."
```

Or run interactively:

```bash
python src/predict.py --essay-set 1
```

You will get something like:

```text
Essay set: 1
Predicted score: 6
Raw model score: 5.73
Valid score range: 0–12
```

## 7. Smoke test without ASAP

You can verify that the code runs before downloading the real dataset.

```bash
python src/train.py --data sample_essays.csv --essay-set 1 --test-size 0.25
python src/evaluate.py --data sample_essays.csv --essay-set 1
python src/predict.py --essay-set 1 --essay "The recycling program is useful because it reduces waste and teaches students to care about their community."
```

The sample dataset is intentionally tiny and synthetic. Its scores are **not** meaningful; it is only a plumbing test.

## What each file teaches you

### `prepare_dataset.py`
Turns the raw ASAP spreadsheet/TSV into a small canonical dataset.

### `features.py`
Converts an essay into numbers:

- TF-IDF word features
- word count
- character count
- sentence count
- average sentence length
- average word length
- unique-word ratio
- paragraph count

### `train.py`
Splits the essays into training/test data and fits a Ridge regression model.

### `metrics.py`
Calculates RMSE, MAE, and QWK.

### `evaluate.py`
Loads a trained model and reports its test-set performance.

### `predict.py`
Loads a saved model and scores a new essay.

## Important limitation

This is a **mini-project / learning implementation**, not a production grading system. Automatic essay scoring has important validity and fairness issues, and a single text model should not be treated as a definitive judgment of a student's writing ability.

## Suggested upgrade path

Once this version works, extend the same codebase rather than replacing it:

```text
Ridge + TF-IDF
      ↓
better linguistic features
      ↓
word/character n-grams
      ↓
BERT/RoBERTa
      ↓
trait-aware scoring
      ↓
explanations + error analysis
```


## Web-scraped training workflow

The project also supports training from **web-collected, scored essays**. The source must permit automated retrieval and use of the essay text for your intended research. The scraper checks `robots.txt` and requires an explicit `--confirm-permission` flag.

Expected scraped CSV schema:

```text
essay,score,prompt,source_url,source_name
```

Example workflow:

```powershell
.venv\\Scripts\\python.exe src\\web_scraper.py --urls urls.txt --essay-selector ".essay" --score-selector ".score" --prompt-selector ".prompt" --source-name "Authorized Source" --output data\\scraped\\essays.csv --confirm-permission
```

Then compare four models:

```powershell
.venv\\Scripts\\python.exe src\\compare_models.py --data data\\scraped\\essays.csv
```

This trains and saves Ridge, LinearSVR, ElasticNet, and SGDRegressor models and writes `results/model_comparison.csv`.

Launch the dashboard:

```powershell
.venv\\Scripts\\python.exe -m pip install -r requirements.txt
.venv\\Scripts\\python.exe -m streamlit run app.py
```

The dashboard shows QWK, MAE, and RMSE for each model, visual comparisons, and predictions from multiple models for a pasted essay.

**Important:** a supervised AES scraper needs a score label for each essay. Plain web essays without human/band scores cannot be used directly to train a regression model.

**Do not scrape a site merely because its pages are public. Check its terms, licence, and robots.txt first.**
